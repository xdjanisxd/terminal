# Terminal 0.2.2-rc.1

First Linux x86_64 release candidate. This candidate is an unpublished portable
GNU/Linux archive; it is not a Debian package and does not require root access.

## Implemented functionality

- GPU-rendered terminal with PTY shells, tabs, nested horizontal/vertical panes,
  scrollback, selection, search, and reusable Saved Workspace templates.
- Configurable shell startup, key bindings, fonts, themes, terminal colors,
  truecolor, opacity, and supported live configuration reloads.
- Documented bounded terminal compatibility, including ANSI colors, indexed and
  truecolor SGR, scrolling regions, alternate screens, and Unicode grapheme
  rendering. See [current state](../CURRENT_STATE.md) and [configuration](../CONFIG.md).
- Linux per-user installer for executable, desktop entry, and eight icon sizes.
  Install, upgrade, and uninstall preserve user configuration and workspace
  data. The executable reports this version through `--version` and `-V`.

This is not complete xterm/VTE compatibility. Unsupported protocol features are
documented in [current state](../CURRENT_STATE.md). Color emoji and some
graphemes depend on installed fonts and renderer support.

## Tested Linux environment

Automated and native release checks were run on Debian 13 x86_64 with the GNU
libc target. The native graphical environment was KDE Plasma Wayland with Intel
Iris Xe Vulkan. This does not establish support for older distributions, GNOME,
standalone X11, or other GPU/driver combinations. The GitHub workflow also
configures Ubuntu 24.04 x86_64 builds; that runner is not a substitute for this
candidate's native interactive acceptance.

The binary is dynamically linked. It needs a compatible GNU libc, the shared
libraries listed by `ldd`, graphics/window-system libraries and a working
Wayland or X11 session supported by winit/wgpu. Fontconfig and installed fonts
provide system font discovery and glyph coverage. Use `ldd ./terminal` to check
the local library resolution. See [Linux release readiness](../LINUX_RELEASE_READINESS.md)
for observed dependencies and test boundaries.

## Install, verify, update, remove

Extract `terminal-linux-x86_64-0.2.2-rc.1.tar.gz`, then verify its checksum
sidecar before installation:

```sh
python3 scripts/package_release.py x86_64-unknown-linux-gnu
cp dist/terminal-linux-x86_64.tar.gz dist/terminal-linux-x86_64-0.2.2-rc.1.tar.gz
(cd dist && sha256sum terminal-linux-x86_64-0.2.2-rc.1.tar.gz > terminal-linux-x86_64-0.2.2-rc.1.tar.gz.sha256)
(cd dist && sha256sum -c terminal-linux-x86_64-0.2.2-rc.1.tar.gz.sha256)
mkdir terminal-linux-x86_64-0.2.2-rc.1
tar -xzf dist/terminal-linux-x86_64-0.2.2-rc.1.tar.gz -C terminal-linux-x86_64-0.2.2-rc.1
cd terminal-linux-x86_64-0.2.2-rc.1
./terminal --version
python3 install_linux.py install
```

Run `python3 install_linux.py install` from a newer extracted archive to
upgrade. Use the same `HOME` and `XDG_DATA_HOME` values for upgrade and removal.
Uninstall with:

```sh
python3 install_linux.py uninstall
```

Uninstall removes installer-owned executable/launcher/icon files. It preserves
configuration, Saved Workspaces, unrelated files, and shared directories. See
the [Linux desktop installation guide](../LINUX_DESKTOP_INTEGRATION.md) for
ownership and desktop-session details.

## Verification commands

From the repository root:

```sh
cargo fmt --all -- --check
cargo test --workspace --all-targets
cargo test --workspace --doc
cargo clippy --workspace --all-targets -- -D warnings
cargo build --locked --release -p terminal-app --bin terminal --target x86_64-unknown-linux-gnu
python3 scripts/test_install_linux.py
python3 scripts/test_package_release.py
python3 scripts/generate_branding.py --check
python3 scripts/package_release.py x86_64-unknown-linux-gnu
```

Check the generated archive with `sha256sum`, then test install, upgrade,
preservation, launcher/icon registration, and removal with temporary HOME and
XDG directories. Interactive KDE launcher/task-manager and Dolphin checks are
listed in the readiness checklist; automation does not prove those UI steps.
