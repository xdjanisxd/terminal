# Terminal 0.2.2

Stable Linux x86_64 release. The portable GNU/Linux archive is not a Debian
package and does not require root access.

## Included functionality

- GPU-rendered terminal with PTY shells, tabs, nested horizontal/vertical panes,
  scrollback, selection, search, and reusable Saved Workspace templates.
- Configurable shell startup, key bindings, fonts, themes, terminal colors,
  truecolor, opacity, and supported live configuration reloads.
- Bounded terminal compatibility, including ANSI colors, indexed and truecolor
  SGR, scrolling regions, alternate screens, and Unicode grapheme rendering.
- Linux per-user installer for the executable, desktop entry, and eight icon
  sizes. Install, upgrade, and uninstall preserve configuration and workspace
  data. `terminal --version` and `terminal -V` report this version.

This is not complete xterm/VTE compatibility. Unsupported protocol features are
documented in [current state](../CURRENT_STATE.md). Color emoji and some
graphemes depend on installed fonts and renderer support.

## Linux requirements

The archive targets x86_64 GNU/Linux and is dynamically linked. It needs a
compatible GNU libc, graphics and window-system libraries, a supported Wayland
or X11 session, and installed fonts. The sign-off record documents the tested
environment and compatibility limits.

## Install, verify, update, remove

Verify the downloaded archive, extract it, and install per-user:

```sh
sha256sum -c terminal-linux-x86_64.tar.gz.sha256
mkdir terminal-linux-x86_64
tar -xzf terminal-linux-x86_64.tar.gz -C terminal-linux-x86_64
cd terminal-linux-x86_64
./terminal --version
./terminal -V
python3 install_linux.py install
```

Run `python3 install_linux.py install` from a newer extracted archive to
upgrade. Use the same `HOME` and `XDG_DATA_HOME` values for upgrade and removal.
Uninstall with:

```sh
python3 install_linux.py uninstall
```

Uninstall removes installer-owned executable, launcher, and icon files. It
preserves configuration, Saved Workspaces, unrelated files, and shared
directories. See the [Linux desktop installation guide](../LINUX_DESKTOP_INTEGRATION.md)
for ownership and desktop-session details.
