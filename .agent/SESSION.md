The focused investigation on perf/windows-powershell-spawn is complete. Seven interleaved release runs per app scenario place median CreateProcessW time at 7.595 ms for cmd, 343.237 ms for pwsh -NoProfile and 351.144 ms for configured pwsh. Native preparation before the call is approximately 0.16–0.19 ms; no production optimization is justified. A standalone ConPTY probe reproduces the large PowerShell delay, while ordinary redirected launches usually return quickly. Internal Windows/PowerShell causation is not established. See docs/WINDOWS_POWERSHELL_SPAWN.md for exact boundary contents, timing tables, reproduction and limitations.
